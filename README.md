# 📌 Overview

**HireFlow AI** is an enterprise-grade **Agentic Recruitment Intelligence Platform** designed to automate and optimize the complete hiring lifecycle.

Unlike traditional ATS systems, HireFlow AI combines **multiple AI agents**, **Explainable AI**, **Human-in-the-Loop approval**, and **predictive workforce intelligence** to help recruiters make faster, smarter, and more transparent hiring decisions.

The platform was built for **Track A – Business Process Automation** and follows an **Agent-Driven Development Lifecycle (ADLC)** with complete workflow traceability and auditability.


```bash

```

Run development server

```bash
npm run dev
```

Build production

